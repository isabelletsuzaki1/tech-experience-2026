# Tech Experience 2026

Projeto Angular desenvolvido para o exercício de Template-Driven Forms e Rotas Aninhadas.

## Como executar

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
npm install
npm start
```

4. Acesse no navegador:

```text
http://localhost:4200/evento
```

## Rotas

- `/evento/inscricao`
- `/evento/programacao`

## O que foi implementado

- Template-Driven Forms
- `ngModel`
- validação dos campos
- mensagens de erro
- campos condicionais
- contador de caracteres
- botão desabilitado enquanto o formulário estiver inválido
- `console.log(this.participante)` ao enviar
- rotas filhas com `children`
- menu lateral permanente
- página de programação
